# 备考总计划 TODO（软考中级 + 省考 + 事业单位）

> 制定时间：2026年8月20日
> 三条线：**软考中级**（拿职称）、**广东省考**（公务员）、**广东事业单位统考**（佛山考区）
> ⚠️ 带"预计"的日期为按上一年规律推算，**必须以当年公告为准**

---

## 零、先想清楚：三条线的关系

### 年龄前提（2026年8月核实公告原文）

⚠️ **广东已把报考年龄上限从35周岁放宽到38周岁**，这是2026年度的新政，此前的"35周岁焦虑"已不适用。

| 线 | 年龄要求 | 关键细节 |
|---|---|---|
| **省考** | 18-38周岁 | 2026年度公告为"1986年10月20日至2007年10月19日期间出生"；应届硕博放宽至43周岁；**公告中没有任何职称放宽年龄的条款** |
| **事业单位统考** | **逐岗位规定，无统一口径** | ⚠️ 公告正文**不写年龄**，年龄写在附件《岗位需求表》里，一岗一定；按**报名首日**计算 |

省考的例外岗位（反而更严）：法官/检察官助理 18-35周岁，一线人民警察 18-30周岁，特警 18-25周岁。

事业单位岗位表里的常见档位（**只是常见，不能预判，必须逐行核对目标岗位**）：

| 条件 | 年龄上限 |
|---|---|
| 一般岗位（本科） | 38周岁 |
| 研究生学历 **或** 中级专业技术资格 | 40周岁 |
| 博士学位 **或** 副高级专业技术资格 | 45周岁 |
| 正高级专业技术资格 | 50周岁 |

⚠️ **职称放宽有"对口"前提**：公告原文写的是"具有研究生学历或**与报考岗位相对应的**中级专业技术资格"。软考中级属计算机/信息系统类，只对口信息技术岗、信息化管理岗、网络安全岗；报教师岗、综合管理岗、卫生岗多半不认。而这类计算机岗本身数量就少（见 [广州事业单位统考.md](广州事业单位统考.md) 第三节）。

**按1991年1月出生推算的可报窗口：**

```
省考（每年10月报名，还剩 4 次）
 2026.10 ✅35岁9个月 → 2027.10 ✅36岁9个月
 2028.10 ✅37岁9个月 → 2029.10 ✅38岁9个月 ← 末班车
 2030.10 ❌39岁9个月

事业单位（每年2月报名，还剩 3 次）※按38周岁常见档估算
 2027.2 ✅36岁1个月 → 2028.2 ✅37岁1个月
 2029.2 ✅38岁1个月 ← 末班车
 2030.2 ❌39岁1个月
 ├ 若持对口中级职称，可够到40周岁档岗位：
 └ 2030.2 ✅39岁1个月 → 2031.2 ✅40岁1个月 → 2032.2 ❌
```

⚠️ 事业单位这一栏是**按常见档位估算的**，不是公告的统一规定。每年拿到《岗位需求表》后，看目标岗位那一行的年龄栏，以那个为准。

⚠️ 38周岁不保证后续年度延续。**每年公告出来第一件事，是核对年龄区间原文**，别按本表想当然。

### 三条线的主次

**它们不是并列的三个目标，而是有主次的。**

| 线 | 目标 | 优先级 | 说明 |
|---|---|---|---|
| **广东省考** | 12月笔试 | **🥇 最高** | 岗位最多、待遇最好，一年只有一次 |
| **事业单位统考** | 次年3月笔试 | 🥈 高 | **行测与省考高度复用**，边际成本极低，等于白捡一次机会 |
| **软考中级** | 11月考试 | 🥉 中 | ⚠️ 见下方说明 |

⚠️ **关于软考的定位，必须先纠正一个误区**：

11月考软考，成绩次年1月出，证书要到**2027年上半年**才拿到手。也就是说——

> **这本证书对眼前这轮省考（2026年12月笔试）和事业单位（2027年3月笔试）都用不上。**
> 它的价值兑现在 **2027年5月之后**。

而且在38周岁新政下，它的三个用途要重新排序：

| 用途 | 实际价值 |
|---|---|
| ~~年龄兜底~~ | ⚠️ **大幅缩水**。省考公告无职称放宽条款，帮助为零；事业单位只是38→40周岁（多出2030、2031两轮），而你到2029年才用得着，且**仅在对口的计算机类岗位上生效**——那类岗位数量本就少 |
| **职称限定岗位** | ✅ 成立。部分岗位直接要求"具有中级及以上专业技术职称" |
| **进编后定级涨薪** | ✅ 成立。专技岗按职称套改薪级，长期收益 |

**所以：软考的理由是"多一类岗位可报"和"进编后涨薪"，不再是"年龄救命稻草"。时间不够时，第一个该让路的仍然是它。**（职称用途详见 [计算机专业快速拿中级职称.md](计算机专业快速拿中级职称.md) 第四节）

## 一、总时间轴（2026年8月 — 2027年7月）

```
2026年
 8月  ████ 软考报名 ⚠️最紧急
 9月  ████████ 软考备考期
10月  ████████ 软考备考 + 【省考报名 10月中下旬】
11月  ██ 软考考试 → ██████ 省考冲刺
12月  ██ 【省考笔试 12月初】→ 休整
2027年
 1月  ████ 事业单位备考（行测复用）+ 软考出成绩
 2月  ██ 【事业单位报名 2月初，仅5天】
 3月  ██ 【事业单位笔试】+ ⚠️【省考面试】← 可能撞车
 4月  ████ 面试 / 补录
 5月  ████ 软考证书到手 → 佛山区专项招聘窗口开启
 6月  ████ 区专项招聘（教育/医疗）
 7月  ████ 区专项招聘
```

### ⚠️ 两个必须提前知道的冲突点

**冲突①：11月软考 → 12月省考，只隔3-4周**

软考考完到省考笔试的切换时间极短，而且知识体系完全不同（项目管理 vs 行测申论）。**对策**：8-10月备考软考期间，行测**不能完全停**，每周至少留2小时保持手感，否则11月切回来会很痛苦。

**冲突②：2027年3月，事业单位笔试 与 省考面试 可能撞车**

省考面试一般在次年3月开始，事业单位笔试也在3月。**对策**：3月一旦收到省考进面通知，**优先省考面试**——面试是已经到手的机会，事业单位笔试只是入场券。这个取舍不要临场纠结。

## 二、分阶段 TODO

### 🔥 阶段0：本周内必做（2026年8月20-31日）

- [ ] **立即查软考下半年报名是否已开放** → [ruankao.org.cn](https://www.ruankao.org.cn/) 选广东考区（⚠️ 报名窗口通常只有1-2周，8-9月开放，**错过就要等明年5月**）
- [ ] 确定软考科目：**系统集成项目管理工程师**（推荐）或 软件设计师
- [ ] 完成软考报名 + 缴费（缴费成功才算报上）
- [ ] 买教材：认准**最新版**（系统集成为第3版，2024年1月出版，旧版考点已废弃）
- [ ] 下载历年真题（渠道见 [计算机专业快速拿中级职称.md](计算机专业快速拿中级职称.md)）
- [ ] 日历上设三个提醒：**10月10日**（省考公告）、**1月25日**（事业单位公告）、**次年3月1日**（软考上半年报名，作为11月没过的备胎）

### 阶段1：软考主攻期（9月1日 — 11月上旬考试）

**节奏：软考60% + 行测保持40%**

- [ ] 第1-3周（9月）：通读教材 + 网课过框架
  - 验收：能默写十大管理领域 × 五大过程组矩阵
- [ ] 第4-6周（9月底-10月中）：背核心考点 + 攻计算题（挣值EV/PV/AC、关键路径、成本）
  - 验收：计算题独立做对
- [ ] 第7-8周（10月中-下）：刷近5年真题，基础知识限时90分钟
  - 验收：基础知识稳定**50分以上**（合格线45）
- [ ] 第9-10周（11月初）：主攻案例分析，练打字答题
  - 验收：案例题能写满、术语用对
- [ ] **每周雷打不动：行测2小时**（言语+资料分析，保持手感即可，不求进度）
- [ ] 考前一周：上官网用**机考模拟系统**练手（⚠️ 案例题要打字作答，界面不熟会丢分）
- [ ] **11月上旬：软考考试**

### 🔥 阶段2：省考报名（10月中下旬，插入进行）

⚠️ **这一段和软考备考重叠，但报名不能拖，就几天时间。**

- [ ] 10月中旬：盯广东人事考试网（rsks.gd.gov.cn）公告发布
- [ ] 公告出来当天：下载职位表，按专业/学历筛选
- [ ] 选岗（参考 [广东省考公务员.md](广东省考公务员.md) 第五节：从化、增城乡镇岗、行政执法类竞争较低）
- [ ] **报名期间每天看12:00/18:00的实时报名人数**，动态调整
- [ ] ⚠️ **确认报名后不能改报**，想清楚再点确认
- [ ] 完成缴费

### 阶段3：省考冲刺（11月上旬 — 12月初笔试）

**软考考完当天就切换，全力省考。这是全年最高优先级的3-4周。**

- [ ] 立刻停掉软考所有内容，不再回看
- [ ] 行测：每天1套限时（重点资料分析、判断推理——性价比最高的两块）
- [ ] 申论：每周2篇完整成文 + 每天30分钟素材积累
- [ ] 考前2周：至少3次全真模拟（**上午行测+下午申论**，按真实考试节奏）
- [ ] 打印准考证 + 确认考点交通
- [ ] **12月初：省考笔试**（2027年度预计12月上旬）

### 阶段4：过渡期（12月中 — 1月）

- [ ] 笔试后估分，判断进面可能性
- [ ] **休整1-2周**（这段时间必须留，连轴转到3月会崩）
- [ ] 1月中：查软考成绩（⚠️ 两科各45分才算过）
  - [ ] 如果**没过** → 报名次年5月上半年软考，重考
  - [ ] 如果**过了** → 关注证书发放通知，留意领取方式
- [ ] 1月下旬：重启行测（此时是复习不是新学，效率高）
- [ ] 如估分乐观：**同步启动面试准备**（结构化面试、时政积累）

### 🔥 阶段5：事业单位统考（2月报名 — 3月笔试）

- [ ] **2月初盯公告**（2026年是2月2日9:00-2月6日16:00，**仅5天**）
- [ ] **五区岗位表一起拉**：禅城、南海、顺德、高明、三水（见 [佛山事业单位统考（三水区）.md](佛山事业单位统考（三水区）.md) 第六节选区策略）
- [ ] 注意：省统考**不限应届、不要求广东户籍**，别被"招聘高校毕业生"标题劝退
- [ ] 报名 + 缴费
- [ ] 2月-3月：按行测体系复习（与省考复用，边际成本低）
- [ ] ⚠️ 笔试科目以笔试前另行发布的公告为准，别按旧年份盲目备考
- [ ] **3月：事业单位笔试**（佛山考区合格线60分，进面1:5）

### 阶段6：面试与收尾（3月 — 7月）

- [ ] 3月：省考面试（如进面）→ **⚠️ 与事业单位笔试冲突时，优先省考面试**
- [ ] 4月：事业单位成绩公布 → 资格复审 → 面试
- [ ] 5月：软考证书到手 → **此时职称开始生效**（事业单位部分岗位年龄由38放宽至40周岁；⚠️ 省考无此条款）
- [ ] 5-7月：**佛山区专项招聘窗口**（教育/医疗系统公告高频期）
  - [ ] 师范背景 → 禅城、南海（招得最多）；往届/在职 → **顺德社会人员场次**
  - [ ] ⚠️ 区公告报名周期常只有5-7天，看到当天就要决定
- [ ] 复盘：如全部未上岸，用职称重新评估下一轮的岗位范围（主要看**职称限定岗位**；年龄上仍在38周岁窗口内，省考还有3次，不必焦虑）

## 三、每周固定动作

不管处在哪个阶段，这几件事每周都要做：

- [ ] **周一**：翻一次三个官网（省人社厅、佛山人社局、三水区政府），看有无新公告
- [ ] **每天**：资料分析 1 组（10分钟，全年不断——这是行测最稳的提分点）
- [ ] **每周日**：回看本周计划完成度，调整下周

## 四、时间不够时怎么砍

按这个顺序放弃，**不要临场纠结**：

```
1. 先砍软考          → 它的收益在下一轮，不影响眼前
2. 再砍事业单位笔试   → 如与省考面试冲突，保面试
3. 绝不砍省考         → 一年一次，岗位最多
4. 绝不砍每天10分钟资料分析 → 成本最低、收益最稳
```
